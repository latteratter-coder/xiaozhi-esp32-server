记忆系统: 加载与保存

xiaozhi-server · mem_local_short 本地短期记忆 · 基于源码分析生成

流程说明

1
连接初始化时 _initialize_memory() 创建记忆提供者实例
2
load_memory() 从 data/.memory.yaml 按设备ID(role_id)加载历史记忆
3
若有 API 端历史摘要记忆(summary_memory)，优先使用；否则使用本地 YAML 文件
4
记忆注入系统提示词的 <memory> 标签内，作为动态 system prompt 的一部分
5
每轮对话 chat() 时调用 query_memory(query) 查询相关记忆，填充到 get_llm_dialogue_with_memory()
6
对话过程中 user/assistant 消息持续累积在 dialogue.dialogue 列表
7
连接关闭时 _save_and_close() 启动守护线程执行 save_memory()
8
拼接完整对话记录 + 历史记忆 + 当前时间戳，调用专用LLM(glm-4-flash)以"时空记忆编织者"prompt 非流式生成结构化 JSON
9
JSON 结果写入 data/.memory.yaml，按设备ID索引存储；或调用 Java API generate_and_save_chat_summary()
