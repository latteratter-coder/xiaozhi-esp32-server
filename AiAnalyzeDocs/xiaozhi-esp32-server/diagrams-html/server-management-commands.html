管理指令处理（server消息）

xiaozhi-server · 双层密钥验证 + 热更新/重启 · 基于源码分析生成

流程说明

1
manager-api (Java) 通过独立的 WebSocket 管理连接发送 {"type":"server"} 消息
2
ServerTextMessageHandler 接收消息，检查 read_config_from_api 是否为 True（仅 API 模式接受管理指令）
3
Secret 二次验证: 消息体中的 content.secret 必须与配置中的 manager-api.secret 匹配。不匹配则返回"服务器密钥验证失败"
4
验证通过，按 action 字段分发指令
5a
update_config → 调用 server.update_config() 从 API 重新拉取配置，重新初始化 VAD/ASR/LLM/Memory 等组件（热更新，不断连接）
5b
restart → 调用 handle_restart() 通过子进程执行重启（subprocess.Popen 启动新进程后退出当前进程）
6
操作完成后通过 WebSocket 返回 {"type":"server", "status":"success/error", "message":"..."}

core/handle/textHandler/serverMessageHandler.py — ServerTextMessageHandler · secret验证 · action分发
core/websocket_server.py — update_config() 热更新配置
core/connection.py — handle_restart() 子进程重启
