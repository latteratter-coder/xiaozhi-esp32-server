统一工具系统架构

xiaozhi-server · 5类执行器的统一分发机制 · 基于源码分析生成

流程说明

1
LLM 流式响应中检测到 tool_calls，传入 UnifiedToolHandler.handle_llm_function_call()
2
解析 JSON 参数: 提取 function_name + arguments，发送工具调用显示消息到设备
3
ToolManager.execute_tool(name, args) 按函数名查找注册的 ToolType，分发到对应执行器
4-5
5类执行器各自执行: Server Plugin(天气/音乐/HA) / Server MCP(stdio/sse) / Device IoT(描述符动态注册) / Device MCP(WS通道) / MCP Endpoint(外部服务)
6
执行器返回 ActionResponse，包含 action(RESPONSE/REQLLM/ERROR) + result + response 文本
