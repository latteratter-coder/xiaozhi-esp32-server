LLM 对话与流式响应处理

xiaozhi-server · chat() 方法完整链路 · 基于源码分析生成

流程说明

1
chat(query, depth=0) 在线程池中执行。depth=0 时创建新 sentence_id，写入用户消息，发送 TTS FIRST 信号
2
将用户消息 Message(role="user") 写入 dialogue 对话历史
3
调用 memory.query_memory(query) 查询历史记忆，返回 memory_str
4
get_llm_dialogue_with_memory() 四段式组装 messages: 静态system(前缀缓存) → few-shot示例 → 动态system(记忆+时间+说话人) → 对话历史
5
调用 llm.response_with_functions(session_id, messages, functions) 获取流式 SSE 生成器
6
逐 chunk 解析流式响应：普通文本实时入 TTS 队列(MIDDLE)；检测 tool_calls 并合并；direct_answer 的 response 参数流式提取直送 TTS
7a
direct_answer 虚拟工具 → 文本已流式播报完毕，提取完整 response 写入对话历史，发送 LAST
7b
real_tool_calls → 并行执行工具调用(超时30s) → 结果写入dialogue → _handle_function_result() → 递归 chat(None, depth+1)
7c
纯文本回复（非function_call模式）→ 拼接完整文本写入历史 → 发送 LAST
8
depth=0 时发送 SentenceType.LAST → TTS 播放线程收到结束信号 → 音频发送完毕 → chat() 返回
