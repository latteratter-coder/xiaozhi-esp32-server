聊天记录上报流程

xiaozhi-server · ASR/TTS/工具调用异步上报 · 基于源码分析生成

流程说明

1
ASR识别/ TTS播放/ 工具调用产生上报数据，通过 enqueue_asr_report() / enqueue_tts_report() / enqueue_tool_report() 入队
2
数据放入连接的 report_queue（Queue 线程安全队列），每个连接独立队列
3
_report_worker() 守护线程持续消费队列，仅在 read_config_from_api=True 且 chat_history_conf!=0 时启动
4
若有 opus 音频数据，先通过 opus_to_wav() 转换为 WAV 格式
5
调用 ManageApiClient.report() → POST /agent/chat-history/report，携带 macAddress、sessionId、chatType(1/2/3)、content、audioBase64
