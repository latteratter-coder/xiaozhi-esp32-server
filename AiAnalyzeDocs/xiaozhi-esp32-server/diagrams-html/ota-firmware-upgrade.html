OTA 固件升级流程

xiaozhi-server · OTAHandler HTTP接口 · 基于源码分析生成

流程说明

1
ESP32 设备启动时发送 HTTP POST 请求到 /api/ota，携带设备 model、version、mac 信息
2
OTAHandler 解析请求体，提取设备型号(model)、当前固件版本(version)、MAC地址
3
若启用认证(auth_enable)，验证请求的 HMAC token；未认证则拒绝
4
扫描 data/bin/ 目录，按 model_version.bin 格式匹配固件文件（带30秒缓存避免频繁IO）
5
_is_higher_version() 语义化版本号比较：服务端版本 > 设备当前版本 → 需要升级
6
AuthManager.generate_token() 生成 WebSocket 连接用的 HMAC token
7
返回 JSON 响应: websocket.url(WS连接地址) + websocket.token(认证token) + firmware.url(固件下载地址) + firmware.version(新版本号)
