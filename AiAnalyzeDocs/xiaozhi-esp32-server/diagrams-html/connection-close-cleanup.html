连接关闭与资源清理

xiaozhi-server · 多路径触发 + 守护线程清理 · 基于源码分析生成

流程说明

1
5种触发源均可导致连接关闭：超时检测 / 客户端断开 / 退出指令 / 输出超限 / 无声音超时(120s)
2
_save_and_close() 在 finally 块中执行，启动两个守护线程并行工作：线程1 生成聊天标题(API) 线程2 保存记忆(LLM摘要)。线程为 daemon=True，启动后不等待
3
守护线程启动后立即调用 close() 执行资源清理（不等待线程完成，daemon 线程在进程退出时自动终止）
4
close() 按源码顺序执行清理：VAD资源释放 → 取消超时任务 → 工具处理器清理 → stop_event.set() → 清空队列 → WebSocket close → TTS close → ASR close → 线程池 shutdown
